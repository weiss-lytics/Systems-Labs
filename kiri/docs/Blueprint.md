# 🌸 Kiri Blueprint

> A beautiful place where ideas go to grow up.

**Status:** 🚧 Work in Progress (Personal Project)

---

# What is Kiri?

Kiri is a personal ideation studio that transforms messy thoughts into structured notes, concise snapshots, and visual blueprints.

It is designed for creators, developers, designers, and builders who constantly capture ideas but struggle to revisit and understand them later.

The goal is not to replace note-taking apps.

The goal is to preserve the **thinking behind the idea**, making it easy for future-you to understand and continue building.

---

# Problem

Current workflow:

Idea → Apple Notes → Forgotten

Months later:

"What was I trying to build again?"

Ideas become walls of text with too much context and no clear direction.

---

# Solution

Kiri transforms:

Messy Thought
↓

Structured Note
↓

Snapshot
↓

Blueprint

The final blueprint becomes a concise reference that explains the idea in under a minute.

# Core Features

### 🌱 Capture

Quickly capture:

- Notes
- Voice ideas
- Screenshots
- Links
- Code snippets

without worrying about structure.

---

### ✨ Refine

AI organizes messy thoughts into:

- Overview
- Features
- Tech Stack
- User Flow
- Challenges
- Future Ideas

---

### 📸 Snapshot

Generate a concise summary for quick reference.

Purpose:

Future-you should understand the entire idea in under 30 seconds.

---

### 📐 Blueprint

Generate a visual blueprint containing:

- Core Features
- Architecture
- User Flow
- Technical Direction
- Roadmap

This becomes the permanent reference for the project.
